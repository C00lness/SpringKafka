# Шпаргалка: Backend-разработка (заметки)

## 🚀 Redis
Сверхбыстрое хранилище в оперативной памяти. Используется для:
- увеличения счётчика;
- кеширования.

## 🗄️ HikariCP
Пул соединений с БД. Настраивается в `application.properties`.  
**Дефолтный размер пула — 10.**

### properties vs yaml
- `properties` — для маленьких проектов.
- `yaml` — для больших проектов со сложной иерархической структурой.

## 🔒 Блокировки БД
Нужны для пользования общими ресурсами.

### Пессимистичная vs оптимистичная
- **Пессимистичная** — транзакция сразу блокируется «на всякий случай».
- **Оптимистичная** — используем механизм версии: версия изменилась → повторяем.

## 📨 Kafka
- `enable.idempotence=true` — по умолчанию для продюсера в Kafka.
- **Частичные отказы** — обрабатываем через `try/catch`: в базу занесём, а Kafka — как получится.

## 🧩 Согласованность данных
- **2PC** — старый подход.
- **SAGA** — «модный молодёжный» подход с компенсирующими транзакциями (чтобы откатить уже созданное).

## 🔢 Версионирование
- версионирование данных;
- версионирование API.

## ⚠️ Обработка ошибок
`@RestControllerAdvice` — для обработки ошибок (используй со стандартными кодами ответов).

## 🔐 Безопасность
- **Keycloak** — сервер идентификации и управления доступом (используется вместо Spring Security).
- **OpenID Connect** — надстройка над OAuth 2.0 для аутентификации.
- **JWKS (JSON Web Key Set)** — публичный ключ, которым Keycloak подписывает токены.
- **ABAC / RBAC** — доступ по атрибутам / по ролям.

## 🧪 @Transactional
Вешаем на `@Service` (логика бизнеса). Либо на метод, либо на класс — в основном на класс.

### 3 грабли
1. Метод должен быть `public`.
2. Нельзя вызывать из того же класса (self-invocation).
3. Свалится, если будет checked-исключение.


### Unit-тесты (Модульные) 
- Один конкретный метод (например, математическую формулу). Моки
### Интеграционные тесты 
- Как компоненты работают **вместе**. Например, что Hibernate реально сохраняет данные в PostgreSQL, или что Kafka-продюсер отправляет сообщение. Медленнее. Требуют поднятия контекста Spring (аннотация `@SpringBootTest` или `@DataJpaTest`).
## Testcontainers 
- Библиотека, которая поднимает **реальные** базы данных (PostgreSQL, MySQL) или брокеры (Kafka) в Docker прямо во время выполнения теста.
## Параметризованный тест (`@ParameterizedTest`) 
один тест прогоняем несколько раз с разными данными. Для мат формул.
## delta (погрешность)

1. http://localhost:8082/actuator/metrics - просто названия метрик
2. http://localhost:8082/actuator/metrics/jvm.memory.used - конкретная метрика (значение)
3. http://localhost:8082/actuator/prometheus - огромная простыня из всех метрик (память, томкэт сессии)

Безопасность в user-service - ## stateless ##. 
При регистрации пароль хешируется BCrypt. При логине AuthenticationManager сверяет пароль с хешем в БД и через JwtUtil выдаёт JWT-токен.
Каждый последующий запрос перехватывается кастомным JwtFilter: он валидирует подпись и срок действия токена, загружает пользователя через UserDetailsService и устанавливает контекст 
безопасности в SecurityContextHolder. В SecurityConfig мы разрешили доступ к /auth/** без токена, а все остальные эндпоинты защитили.
